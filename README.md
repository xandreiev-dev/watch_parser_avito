# Avito Watch Parser

Парсер объявлений с Avito для умных часов.
Сделан как часть пайплайна для дальнейшего анализа и матчинга моделей.

Проект собирает объявления, очищает их и готовит к следующему этапу — сопоставлению моделей и записи в БД.

---

## Что делает парсер

Парсер:

* проходит по списку ссылок с Avito
* собирает объявления (цена, описание, продавец и т.д.)
* извлекает доставку (например: *"Доставка от 1 дня"*)
* фильтрует мусор
* убирает дубликаты
* сохраняет результат в Excel

---

## Логика работы

Парсер разбит на два отдельных прогона:

* **NEW** — новые товары
* **USED** — б/у товары

После запуска создаются 2 файла:

```
result/
 ├── Avito_ru_new.xlsx
 ├── Avito_ru_used.xlsx
```

---

## Структура проекта

Основные файлы:

* `parser_cls.py` — основной парсер
* `dto.py` — конфиг (AvitoConfig)
* `models.py` — модели данных (объявления)
* `config.toml` — настройки

---

## Конфигурация

Файл: `config.toml`

### Основное

```
new_urls = [ ... ]
used_urls = [ ... ]
```
 Два списка ссылок:

* новые объявления
* б/у объявления

---

### Ограничения и фильтры

```
min_price = 0
max_price = 99999999

keys_word_white_list = []
keys_word_black_list = []

seller_black_list = []
```

---

### Анти-бан (важно)

```
pause_between_links = 4
max_count_of_retry = 5
proxy_rotation_limit = 15
proxy_rotation_cooldown = 10
```

Что реализовано:

* случайные паузы между запросами
* retry при ошибках
* смена IP
* защита от повторных страниц

---

### Прокси

```
proxy_string = "login:pass@host:port"
proxy_change_url = "https://..."
```

## Что именно парсится

С каждого объявления:

* title (название)
* price (цена)
* url
* description
* sellerId
* rating
* delivery (очень важно)
* images

---

## Фильтрация

Фильтрация идет через `AdsFilter`:

* по цене
* по ключевым словам
* по продавцам
* по возрасту объявления

---

## Дедупликация

* по ID объявления
* по hash страницы

## Как запустить

### 1. Установить зависимости

```
pip install -r requirements.txt
```

---

### 2. Запуск (основной режим)

```
python parser_cls.py
```

---

## Важные моменты

### Защита от 429

Реализовано:

* random delay
* retry логика
* смена прокси
* остановка при дублях страниц

---

### Парсер НЕ делает матчинг

Он только подготавливает данные.

Дальше пайплайн такой:

```
Avito → raw.xlsx → cleaning → matching → DB
```

## Следующий этап проекта

   * `g_watch`
   * `g_shop_watch`
